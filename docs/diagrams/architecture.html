Up to you — Architecture

One docker compose up: nginx, FastAPI, PostgreSQL 17 + pgvector, Airflow 3, and a model service that stays off until a backfill runs.

One port, on purpose

  • • :8080 is the only port the product publishes. The API and the database are reachable over the compose network and nowhere else.
  • • :8081 is the orchestrator's own UI — a second published port, and it is not the product.
  • • nginx strips /api/ before forwarding, so the FastAPI routers must not carry the prefix.

One worker, argued not solved

  • • Live room state is per-process, so a second uvicorn worker would serve two people in one room different rooms.
  • • The no-cache rule forbids the usual escape hatch of an external pub/sub layer, so the limit is stated instead of engineered around.
  • • Async end to end: a synchronous driver blocks the one event loop, and while it is blocked nobody is served.

The model is a guest

  • • Behind a compose profile: docker compose --profile model up -d ollama. Nothing in the request path touches it.
  • • Classification is a batch over one township, committing every 25 rows, so an interrupted pass resumes rather than restarts.
  • • Exit 3 means the service is not up and nothing was written — an ordinary answer, not a failure.
